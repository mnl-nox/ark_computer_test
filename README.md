## Objetivo

Centralizar código, scripts e validações para execução e manutenção do projeto em Linux, usando Python e Bash.

## Execução

Com Python 3 instalado, execute o experimento a partir da raiz do repositório:

```bash
python3 src/test_cpu.py
```

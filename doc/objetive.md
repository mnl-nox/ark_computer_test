# Objetivo

O repositório `ark_computer_test` reúne experimentos e validações simples para execução no ambiente ARK Computer. No estado atual, contém um exemplo mínimo de carga de CPU em Python: somar uma sequência de inteiros e registrar o tempo gasto.

## Escopo atual

- Demonstrar a execução de um script Python sem dependências de terceiros.
- Observar, de forma básica, o tempo de uma operação computacional em memória.
- Manter espaço para futuros testes e experimentos relacionados ao ambiente Linux.

Este código é demonstrativo. Não é uma ferramenta de benchmark rigorosa nem um teste automatizado de conformidade do ambiente.

## Fora do escopo atual

O repositório ainda não configura instalação, integração contínua, coleta de métricas, execução de múltiplos cenários ou comparação estatística de resultados.
